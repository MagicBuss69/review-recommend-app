# 🐾 BiteBuddy

*Your buddy who knows where to eat.*


An app where you **paste a link** to a restaurant, café, or any business — and it tells you:

- ⭐ **How it's doing on reviews** (a clear, honest summary)
- 💰 **A read on how the business is doing** (a "health" estimate)
- 🍝 **A personal food recommendation** — tell it what you like and dislike to eat,
  and it suggests what *you* should order.
